# FUNCTIONS is the main panel of the Comando OS
Functions does the job of  System monitor, Resources manager, Produtivity workspace all in command line interface.

# Concept
It configure as a full use of the F1-F12 keys. System monitor, Process handling, Shell interpreter, Text Browser, Text Editor, AI Agent, all that using a terminal:
F1 - F4 System Monitor (CPU, MEM, DSK, NET)
F5 - F8 Process Handler (MDL, PRC, SRV, TSK)
F9 - F12 Productivity (SHL, VIM, BRW, AGT)
