# FUNCTIONS
Functions does the job of System monitor, Resources manager, Productivity workspace all in one application.

# Concept
Configurable by Fn keys. Help navigator, System monitor, Process handling, Shell interpreter, Text Editor, Browser, Internet Relay Chat client/server:

F1 - F4 System Monitor (CPU, MEM, DSK, NET)
F5 - F8 Process Handler (MDL, SRV, PRC, TSK)
F9 - F12 Productivity (SHL, VIM, BRW, IRC)
