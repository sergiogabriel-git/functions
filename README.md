# FUNCTIONS
Functions does the job of  System monitor, Resources manager, Productivity, workspace all in one.

# Concept
It configure the F1-F12 keys in qwerty keyboards. System monitor, Process handling, Shell interpreter, Text Editor, Text Browser, Internet Relay Chat all that using a terminal:

F1 - F4 System Monitor (CPU, MEM, DSK, NET)
F5 - F8 Process Handler (MDL, SRV, PRC, TSK)
F9 - F12 Productivity (SHL, VIM, BRW, IRC)
