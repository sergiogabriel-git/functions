# functions
Functions does the job of control panel, system dashboard and produtivity workspace all in one terminal interface.

# Concept
It is configured as a full use of the Fn keys as a active function of the program. System monitor, Process handling, Shell interpreter, Text-only Browser, AI Agent using Ollama, all that using a terminal interface.

# Description
F1 - F4 System Monitor (CPU, MEM, DSK, NET)
F5 - F8 Process Handler (MOD, PRO, SRV, TSK)
F9 - F12 Productivity (SHL, VIM, BRW, AGT)
